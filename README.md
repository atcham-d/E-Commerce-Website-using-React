# 🛍️ Simple eCommerce Website

This is a basic eCommerce website built with HTML and CSS. It features responsive design, common pages like Home, About, Contact, Login, and Register.

---

## 🌟 Features


- 📱 **Responsive Layout**
- ✨ Google Fonts Integration (`Merriweather`, `Poppins`)
- 📄 Pages: Home, About, Contact, Login, Register
- 🔗 External Stylesheet (`style.css`)
- Backend integration with mongodbatlas database
- jwt authentication

---
